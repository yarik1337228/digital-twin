Методы расчета антенн в HFSS
•	Метод конечных элементов FE (Finite Element Method)
o	HFSS вычисляет поля в объёме
o	Используется с граничными условиями вокруг области FEM: Radiation, FE-BI и PML
•	Метод интегральных уравнений IE (Integral Equation)
o	Поля и токи рассчитываются на поверхности
o	Распределение поля в пространстве рассчитывается из плоской сетки
o	Поля в дальней зоне можно рассчитать на основе элементов 2D-сетки в IE
•	Гибридные регионы FE-BI облегчает совместное моделирование на расстоянии
o	Формулировка FE-BI включает моделирование на границе
o	Рупор в гибридной области FE-BI может возбудить отражатель с областью IE
o	Пространство между двумя объектами не требует создания сетки или моделирования
•	SBR+ преодолевает расстояние без необходимости построения сетки в объеме
o	SBR+ асимптотический лучевой метод (SBR = стреляющий, отскакивающий луч)
o	Моделирование рупора и отражателя можно выполнить, установив для отражателя гибридную область SBR+
o	Объединение нескольких гибридных регионов в одном проекте

Эффективная площадь рассеяния (ЭПР)
Эффективная площадь рассеяния (ЭПР), обозначаемая как σ и называемая также радиолокационной сигнатурой или RCS (Radar Cross-Section), представляет собой меру обнаружимости объекта радаром 
Определение: ЭПР - это эффективная площадь, которая перехватывает плотность мощности падающей волны таким образом, что если бы вся перехваченная мощность переизлучалась изотропно (равномерно во все стороны), то создавалась бы наблюдаемая плотность мощности в приемнике 
Физический смысл: ЭПР можно представить как площадь идеально отражающей сферы, которая создала бы такой же уровень отраженного сигнала, как и исследуемый объект. При этом ЭПР не обязательно связана с физической площадью объекта, а зависит от множества факторов 
Факторы, влияющие на ЭПР:
1.	Материал объекта (электропроводность, диэлектрическая проницаемость)
2.	Размер объекта относительно длины волны
3.	Абсолютные размеры объекта
4.	Угол падения волны (зависит от формы и ориентации объекта)
5.	Угол отражения (направление рассеяния)
6.	Поляризация излучения относительно ориентации объекта
